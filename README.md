## Question Categories (Study Guide)

The quiz assesses baseline understanding across six core categories:

### 1. Concepts Discussed During the IDS Pre-Orientation
- **Digital Identity Stack (IDS) Architecture:** Foundational components, trust model, and platform workflows.
- **Self-Sovereign Identity (SSI) Framework:** The Issuer -> Holder -> Verifier triad and trust registries.
- **IDS Sandbox:** Sandbox capabilities, credential definitions, and developer environments.

### 2. Digital Technologies Relevant to the Competition
- **Decentralized Identifiers (DIDs):** DID structure, resolution, and DID Documents.
- **Verifiable Credentials (VCs):** Claims, schemas, credential definitions, and cryptographic signatures.
- **Verifiable Presentations (VPs):** Presenting claims, selective disclosure, and zero-knowledge proof concepts.
- **Revocation Registries:** Dynamic status checking and cryptographic revocation validation.

### 3. Technology Fundamentals
- **Web & API Architectures:** Client-server models, RESTful endpoints, WebSockets, JSON payloads.
- **Cryptography Basics:** Asymmetric public/private key pairs, hashing functions (SHA-256), and digital signatures.
- **Data Security:** Transport layer security (TLS), integrity checks, and basic threat models.

### 4. Programming & Computational Thinking
- **Algorithmic Logic:** Control flow (loops, conditionals), function composition, and recursive patterns.
- **Data Structures:** Key-value maps, arrays, queues, and tree-based structures.
- **Problem Decomposition:** Breaking complex specifications into executable logic steps.

### 5. Problem-Solving & Debugging
- **Code Tracing:** Reading code snippets, predicting output, and identifying logic flaws.
- **Error Diagnosis:** Handling null/undefined pointers, off-by-one errors, and unhandled edge cases.
- **API Troubleshooting:** HTTP status codes (`200 OK`, `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `500 Internal Error`).

### 6. Basic Product & Innovation Concepts
- **Problem-Solution Fit:** Defining user pain points and validating solution value.
- **Product Thinking:** Minimum Viable Product (MVP) scoping, user journey mapping, and feasibility constraints.
