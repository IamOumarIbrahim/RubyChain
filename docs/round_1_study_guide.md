## Qualification Rules & Tie-Breakers

- **Passing Rule:** The top 20 scoring teams qualify for Round 2.
- **Tie-Breaker Order (if cutoff scores are tied):**
  1. Higher number of correct answers.
  2. Faster completion time (submission speed on Kahoot / Quizizz).
  3. Pre-selected tie-breaker challenge question.
- **Authority:** The organizing committee's decision is final.

## Study Guide: Topic Breakdown

| Category | Key Concepts to Master |
| :--- | :--- |
| **1. IDS Pre-Orientation** | Digital Identity Stack (IDS) architecture, Self-Sovereign Identity (SSI) Issuer-Holder-Verifier triad, and IDS Sandbox tools. |
| **2. Digital Identity Technologies** | Decentralized Identifiers (DIDs), Verifiable Credentials (VCs), Verifiable Presentations (VPs), and Revocation Registries. |
| **3. Tech Fundamentals** | REST APIs, JSON payloads, WebSockets, public/private key cryptography, SHA-256 hashing, and HTTPS/TLS integrity. |
| **4. Programming & Logic** | Algorithmic control flow, conditionals, core data structures (arrays, hash maps, queues), and problem breakdown. |
| **5. Problem-Solving & Debugging** | Code tracing, error diagnosis, edge cases, and standard HTTP status codes (`200 OK`, `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `500 Server Error`). |
| **6. Product & Innovation** | Problem-solution validation, MVP scoping, user journey mapping, and feasibility. |
